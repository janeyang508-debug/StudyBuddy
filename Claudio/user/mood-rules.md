# Mood Rules

These rules help Claudio pick the right vibe automatically.

## Weather-based
- Rainy day → jazz, soft indie, melancholic ballads
- Sunny → upbeat, bright, feel-good pop
- Cold → warm acoustic, cozy vibes

## Day-based
- Monday morning → motivating, not too intense
- Friday evening → celebratory, energetic
- Sunday → nostalgic, reflective

## Override Rules
- If I say "focus" → switch to instrumental immediately
- If I say "surprise me" → pick something outside my usual taste
- If I say "something new" → no repeat artists from last 3 plays
